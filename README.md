# YouTube-Downloader-Save-Videos-as-MP4-or-MP3-in-One-Click
Streamlit web app for downloading YouTube videos as MP4 (best video and audio, merged with FFmpeg) or 192 kbps MP3, built on yt-dlp. It previews the title and length, cleans up temporary files, and runs locally, in Codespaces or on Streamlit Cloud
